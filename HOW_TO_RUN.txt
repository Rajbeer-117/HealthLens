 HealthLens - Deliverable 2 (AI + LLM)   |   Group 7, COMP 8967

WHAT YOU NEED (one time)
  1. Python 3.11 or newer  ->  https://www.python.org/downloads/
     (during install, TICK "Add Python to PATH")
  2. Ollama (free local AI) ->  https://ollama.com/download
     Just install it. No account needed.

--------------------------------------------------------------
 EASIEST WAY: double-click  run_with_llm.bat
--------------------------------------------------------------
  It will automatically:
   - start Ollama
   - download the AI model "llama3.2" (about 2 GB, first time only)
   - create the Python environment and install packages
   - start HealthLens and open http://127.0.0.1:5000 in your browser
  KEEP THE BLACK WINDOW OPEN while using the app (closing it stops the app).

--------------------------------------------------------------
 OR RUN IN VS CODE
--------------------------------------------------------------
  1. VS Code -> File -> Open Folder -> choose this folder (the one with app.py)
  2. Terminal -> New Terminal, then type:
        py -m venv .venv
        .venv\Scripts\activate
        python -m pip install -r requirements.txt
        ollama pull llama3.2
        python app.py
     (if "activate" gives a red "running scripts is disabled" error, run first:
        Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass )
  3. Open http://127.0.0.1:5000 in Chrome
  Next time only:   .venv\Scripts\activate   then   python app.py
  Stop the app:     click the terminal, press Ctrl + C

--------------------------------------------------------------
 THE APP: SUMMARY, PROFILE, DOCUMENTS + CHATBOT
--------------------------------------------------------------
  1. Sign up / sign in.
  2. Summary   - LEFT PANEL: 3 categories (Metabolic, Cardiovascular,
                 Women's health / PCOS) + 'All measures'. Click one to see its
                 signal checks; readings, flags and charts then show only that
                 category. DATA SPAN switch: 'Last 3 months' (default) or
                 'Full record'.
                 Also shows key readings, recent flags and trend charts for the
                 selected patient (use "Demo patients" / "My uploads"
                 and the Patient menu at the top right of the page).
  3. Profile   - your account details plus the patient's details and
                 medical history (conditions and medications).
  4. Documents - upload patient workbooks (.xlsx, or a .zip of .xlsx),
                 supporting files (PDF, Word, CSV, TXT, PNG, JPG), or import
                 a file from Google Drive by pasting its share link
                 (sharing must be "Anyone with the link").
  5. Chatbot   - the round "Ask HealthLens" button at the bottom-right of
                 every page. Click a suggested question or type your own.
                 "Do I have diabetes?" gives a safety reply: it never diagnoses.
     In the chat header, a GREEN dot = an LLM is connected; ORANGE =
     offline template answers (open the Ollama app, wait 10 s, refresh).
     The first LLM answer can take 30-60 s while the model loads.
