      How the AI layer works
      
      
        
    1. Data preparation: all 11 workbook sheets cleaned and dated.
      2. 
        
    2. Explainable engine: trends (Mann-Kendall + Theil-Sen), anomalies (robust z-score vs personal baseline), reference ranges, relationships (Spearman), medication timing, data quality.
      3. 
        
    3. Evidence register: each finding becomes a numbered evidence item with method and source.
      4. 
        
    4. De-identification: only age band, sex and evidence text with relative dates are sent to the LLM.
      5. 
        
    5. LLM: writes the explanation as JSON citing evidence IDs.
      6. 
        
    6. Guardrails: unknown evidence IDs, diagnosis, risk scores, alarm/emergency wording and medication advice are rejected; one corrective retry, then a safe template fallback.
      7. 
        
    7. Audit log: each AI call is logged (no question text, no health values) in logs/ai_audit.jsonl.

    How HealthLens handles missing data
    
    
      
      
    • Blank cells are dropped per measure; nothing is interpolated or imputed.
      • 
      
    • Daily data is averaged per week before trend tests, so a few missing days do not create false trends.
      • 
      
    • Trends need at least 8 weeks of data (or 3 lab draws); anomalies need 14 prior days of baseline.
      • 
      
    • Scenario checks report "no data" for missing signals instead of treating them as normal.
      • 
      
    • Data limitations are passed to the LLM as evidence so explanations can mention them.
      •
